```
Application configuration:
- SMTP host: smtp.emaillabs.io (or similar)
- Port: typically 587 (TLS) or 465 (SSL)
- Username: provided by EmailLabs
- Password / SMTP key: provided
- TLS/SSL: yes
   ↓
Application sends emails via SMTP:
- Standard SMTP protocol
- No code changes required (existing apps)
- Plug-and-play
   ↓
EmailLabs receives:
- Authenticates
- Applies DKIM signing
- SPF compliance check
- DMARC alignment
- Routes via optimal IP
- Delivers to recipient ISP
   ↓
Tracking automatic
```
