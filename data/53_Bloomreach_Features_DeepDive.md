### 4.3 Event-based pricing implications

⚠️ **Klíčový rozdíl od Klaviyo / Mailchimp** – Bloomreach pricing je **per event**, ne per contact!

```
Pricing model porovnání:

Klaviyo: per contact
- 1000 kontaktů = X
- 10000 kontaktů = 10X

Mailchimp: per contact
- Stejně

Bloomreach: per processed event
- 1M eventů = X
- 10M eventů = 10X (s discount)

Co je "event"?
- Page view
- Email send
- Click
- Purchase
- Cart action
- Custom event (API)
- Profile update
   ↓
Event-heavy businesses = drahé
Low-event lite usage = výhodné
```
